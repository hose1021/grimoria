# Design

Keep the persisted baseline distinct from the normalized state shown to the host. Recovery must preserve the live session, retain exact damaged bytes, and allow clean windows to adopt an external repair. Bind service-worker caches to each registration, provide network fallback for unreadable caches, and track deferral against the waiting worker. Validate a downloaded language catalog before publishing it. Translate the seat editor's live status from its action and arguments, inserting names literally.
