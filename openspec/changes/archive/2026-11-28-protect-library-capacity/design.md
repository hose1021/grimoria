# Design

Check the number of saved entries before adding a new ID. Enforce the limit independently for bags and pools. At capacity, an existing ID can still be updated. An oversized write or import must report a capacity error before it can replace library data. The screen must update its displayed library only after the write succeeds and explain how the host can make space.

The verification workflow supplies the comparison revision to both gate jobs for each supported event. The source policy checks maintained files in the current working tree, including new source files, while excluding ignored working copies and generated dependencies.
