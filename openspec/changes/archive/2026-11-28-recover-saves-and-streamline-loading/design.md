# Design

Use the on-disk v4 value as the optimistic concurrency baseline independently of the legacy backup. Keep an active game open across a worker change until the host confirms and persistence succeeds. A completed game and a fresh setup use the existing update behavior.

Build the offline list from emitted chunks, supported catalogs, selected role art and stylesheet font URLs. Load the requested catalog and the route that the visitor opens. Keep the countdown clock local to its display. Make edition links addressable and retain the sheet preference for ordinary navigation. Share in-flight reference requests and evict failures.
