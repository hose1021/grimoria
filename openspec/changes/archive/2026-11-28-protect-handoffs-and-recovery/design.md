# Design

Tie the open card to the game and its player assignment. Refresh the seating editor from externally committed orders and protect a pending edit from overwriting a conflicting arrangement. Revalidate release resources at installation and limit role art to supported characters and the sheet’s Travellers. Load catalogs with browser-compatible promises and honor the most recent language selection.

Apply bag-library changes against current storage, preserve failed notes in a usable backup, and recognize a pristine game before its first disk write. Apply a successful command once under the existing rollback boundary. Keep fragment navigation native and use an accessible file picker.
