# Role ownership ledger

Generated by `node scripts/role-ownership.ts` from the role modules, the
coordinator sources and every `rule.md`. Do not edit by hand: run the
generator, then review the diff. `--check` fails on a stale ledger.

## How to read a row

- **Module facts** are the declarations in `src/core/roles/<role>/role.ts`.
- **Engine references** count role literals in the coordinating files. A
  capability row with engine references is a migrated rule that the engine
  still names to route the step; an engine-branch row is rule logic that
  has not moved into a typed capability yet.
- **Shared writers** are listed in `src/core/roles/architecture.test.ts`;
  only those engine owners may call a shared death, execution,
  transformation, effect or win writer.
- **Rules** lists the rule identifiers from `rule.md`, with their matrix
  level and pinned revision.

A role literal in a coordinator is the remaining migration debt. Every
exception must either move into a typed capability or carry a pinned
source justification in the role dossier.
